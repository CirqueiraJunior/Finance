# Sprint 01 — Fundação

## Escopo entregue

- Estrutura em camadas e empacotamento Python.
- Configuração tipada por variáveis de ambiente.
- Logging em console e arquivo rotativo.
- SQLAlchemy com suporte configurável a SQLite/PostgreSQL.
- Ambiente Alembic sem tabelas de domínio.
- Shell PySide6 com janela principal, barras, menu, navegação e placeholders.
- Testes de configuração, banco, navegação e janela.

## Decisões

- Nenhum modelo de negócio foi inventado.
- Nenhum CRUD ou operação de dados foi implementado.
- Os módulos do domínio serão definidos depois do levantamento funcional.
- SQLite é o padrão local; PostgreSQL é selecionado apenas por configuração.
